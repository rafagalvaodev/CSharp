# CSharp

Repositório de estudos, exercícios e projetos em C#.

O foco é praticar fundamentos da linguagem e experimentar diferentes tipos de aplicação, como console apps, APIs, Windows Forms e testes unitários.

## Estrutura

- `Estudos/`: exercícios e exemplos por tema.
- `Projetos/`: projetos mais completos e desafios práticos.

### Temas comuns em `Estudos/`

- Condicionais: `if`, `switch`
- Estruturas de repetição: `for`, `foreach`, `while`
- Coleções: arrays, listas e vetores
- Fundamentos de POO: classes, objetos, abstração e delegate
- Exercícios de lógica: tabuada, fatorial, Fibonacci, conversões e cálculos
- Interfaces gráficas e aplicações desktop

### Tipos de projeto

- Console
- ASP.NET Core Web API
- Windows Forms
- Testes unitários

## Requisitos

- .NET SDK 6 ou 7 para a maior parte dos projetos recentes
- Visual Studio para projetos antigos em .NET Framework e para Windows Forms

## Como executar

Cada pasta normalmente contém sua própria `solution` e seu próprio projeto.

### Pelo terminal

```bash
dotnet run --project "caminho/para/o/projeto.csproj"
```

### Pelo Visual Studio

1. Abra o arquivo `.sln` do projeto desejado.
2. Defina o projeto de inicialização, se necessário.
3. Execute com `F5` ou `Ctrl+F5`.

## Observações

- Há projetos em diferentes versões do .NET.
- Alguns exemplos usam a estrutura antiga do Visual Studio/.NET Framework.
- Os nomes das pastas refletem o tema estudado em cada exercício.

## Objetivo

Manter uma base prática para estudo contínuo de C# e revisão rápida de conceitos.
